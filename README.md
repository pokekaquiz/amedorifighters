## オフライン利用
初回オンライン時に、出題したいセット・店舗・カテゴリを選んで
「現在の選択範囲をオフライン保存」を押してください。

今回キャッシュのバージョンを更新しているため、
以前の版で保存したオフライン画像は、新版で再保存してください。
